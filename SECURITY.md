# Política de segurança

## Reportar uma vulnerabilidade

Não abras uma issue pública. Usa o [reporte privado de vulnerabilidades do GitHub](../../security/advisories/new) deste repositório.

Inclui:

- descrição do problema e impacto;
- passos para reproduzir;
- versão ou commit afetado.

Respondo em até 7 dias. Depois de corrigido, o problema é descrito num security advisory.

## Versões suportadas

Só a versão em produção (a última tag na `main`) recebe correções de segurança.
